# Arduino Claw

A team-built Arduino claw combining sensors, motors, and control code.

[Portfolio overview](https://felixchen2007.github.io/projects/arduino-claw/)

![The Arduino claw prototype with its mechanical structure and electronics](images/arduino-claw-1.jpg)

## Project details

- Contribution: Five-person team
- Tools: Arduino / Sensors / Control
- Discipline: Electromechanical design

## Documentation

Bringing mechanical construction and embedded control together.

### Building an integrated prototype

In a five-person team, I helped build and program an Arduino claw combining motors, sensors, and mechanical parts. My contributions included sensor-reading and control logic, assembly, and wiring.

### Testing under real constraints

We tested and debugged the integrated system for tasks involving object handling, timed foam-block collection, and cooperative lifting. The competition required the mechanism and control logic to work reliably together.

### Putting it to the test

The team achieved top studio scores across the three-round competition. The project was an exercise in iteration, hands-on integration, and coordinating a build as a team.

### Design focus

- Arduino-based control
- Motor and sensor integration
- Wiring and mechanical assembly
- Three-round studio competition
